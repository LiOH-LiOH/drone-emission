## 选定主来源

Li, Z., Zhou, S., Wang, B., Zhang, T., Guo, S. (2025). **Beyond the last-mile: Environmental and economic assessment of the upcoming drone takeaway delivery system.** *Sustainable Cities and Society*, 120, 106134. [DOI与出版社入口](https://doi.org/10.1016/j.scs.2025.106134)。已有全文：[li_2025.md](../ref/md/li_2025.md)。

它以南京栖霞的外卖配送为场景，在统一LCA/TCO框架内比较电动自行车和小型无人机，给出两种方式的成本公式与配套情景。因此优先于卡车—无人机论文，也优先于汽油摩托车基准的国外外卖论文。它是本项目经济模型的主来源，而非仅作讨论引文。

此前将该文排除出核心参数来源，是将“顶刊/独立实测”误当成了本次建模的必要门槛。当前按用户的“学术可接受即可”标准，采用已发表、场景相关且可复现的模型。来源中含有估计或引用其他研究，本身不妨碍采用；无需逐条重新证明。

## 已从正文取得的统一模型

原文§3.3将TCO分成固定费用与可变费用。我们采用运营部分，目标是成本而不是利润或回本周期。

| 原文位置 | 内容 | 项目处理 |
|---|---|---|
| 式(6) | 设备、柜体初购及残值相关固定费用 | 排除，符合成熟运营、仅运维边界 |
| 式(7) | 电动车和无人机电池更换、人工、两种方式充电及柜体运行费用 | 作为统一运营费用骨架，再按方式和订单分配 |
| 式(8) | 骑手人工与商场工作人员人工 | 沿用其计件与日薪两种口径，不另建全国工资调查 |
| 式(9) | 随距离变化的配送计价 | 结合式(8)中的骑手报酬比例，构造骑手每单人工函数 |
| 式(10)、(11) | 电动车与无人机充电费用 | 接入项目已有能耗核算，保留原文电价等经济输入；注明这是能耗输入适配 |
| 式(12) | 柜体运行费用 | 只在采用柜体服务链时加入；当前商家—建筑OD若不引入柜体，不凭空新增柜体设施与运行项 |
| Table 1、Table S7 | 基准/未来参数与完整变量说明 | 按整套情景提取，默认不混用其他论文的低成本参数 |

正文的距离计价（d以km计、费用CNY/单）为：

```text
p(d) = 2.8                       (0 < d <= 3)
       2.8 + 1.4 * (d - 3)        (d > 3)

c_rider_labor(d) = 0.7 * p(d)     [原文式(8)与式(9)]
```

这提供了无需逐单工资调查的既有建模规则。0.7按作者的骑手报酬模型采用，不把p(d)全部当工资，也不把平台保留部分作为系统人工消耗。它是来源模型中的报酬代理，不宣称为当前全国统一收费规则。

正文还给出商场员工日薪200 CNY（未来情景300）、无人机电池1000 CNY/包（未来600）及电动车电池400 CNY/组。具体使用时结合该论文配套服务量、寿命与S7解释，而不是另找不同论文逐项拼接。式(7)对更换电池采用0.95的净费用系数，源自其残值设定，须与初装电池/资本费用的剔除方式保持一致。

## 接入当前研究的最小适配

1. **保持现有科学输入。** 使用已有城市OD、订单权重、道路/空中距离及能耗；不移植南京的订单位置或重做原文AnyLogic调度。经济参数与核算逻辑以Li 2025为主。
2. **保持已选目标。** 每个OD分别按生命周期排放、运维成本、单程运输时间选择方式，再按订单量汇总三个替代率。时间仍只含运输，不恢复等待与取餐建模。
3. **剔除投资和收益。** 不纳入初购、设施建设、设备折旧、回本和营业收入。运营性电池更换及人工保留；柜体是否存在按项目服务链处理。
4. **做必要的费用分配。** 电动车成本由原文距离报酬、充电、电池更换等组成；无人机由地面人工分摊、充电、电池更换等组成。年度/每日共享费用按采用情景的服务量分摊，并作为逐OD选择的给定单位成本，不暗中变成机队联合优化。
5. **保留已确认的监管人工。** S7已确认列骑手和商场员工，没有远程飞手或一人多机数值。监管人工保留为简洁的显式扩展项，不伪称主来源已提供数值。
6. **明确维修覆盖。** S7没有维修行，S8明确不计车辆部件损耗（电池除外）。原文运营基准与含维修附加项的完整运维情景分开报告；扩展采用综合项，不为所有零部件另找来源。

允许为主来源未覆盖、且用户已明确要求的项目增加少量假设或一个补充来源。“统一来源”是保持主体模型一致，不是声称一篇论文已经覆盖全部设定；也不是把两个交通方式分别接入完全不同经济模型。
