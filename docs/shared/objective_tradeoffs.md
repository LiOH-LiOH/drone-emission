# 减排与运营目标比较

范围：锁定313研究城市；分析代码、独立候选子图、结果总结，不改文章或发布旧图替换。四种最优策略为碳排放、保守经济、乐观经济、运输时间；全电动车与全无人机为参照。

经济参数沿用南京已确认模型：保守设备60000/1000元、8小时、每架1名飞手200元/天；乐观40000/600元、12小时、无飞手；全年300天。电动车两种情景均为8小时。地面人员保留。两种经济情景对全部六种配置交叉计价，固定订单分配后按任务工时配置车队和共享设施。

排放沿用原运输生命周期口径；运输时间为已有单程运输时间，不含排队、等待和取餐。设施成本纳入经济指标，不新增设施排放核算。没有折中优化或额外敏感性扫描。

## 入口与数据

```sh
python -m drone_emission --env remote cost-pilot --region nanjing --objectives
python -m drone_emission --env remote analyze --only objective-tradeoffs --reuse-from <audited-reuse-directory>
python -m drone_emission --env remote render --only candidate_objective_tradeoffs
```

结果在工作目录 `analysis/objective_tradeoffs/`：city_strategies.csv、cohort_strategies.csv、report.json、summary.md；单城结果在其pilot/nanjing子目录。每城保留带输入及参数签名的检查点，失败重试不会重算已完成城市。全量只求每城两个经济最优解，不计算固定替代率曲线。

原100米道路/空中距离组进一步按原始OD的碳最优和时间最优选择拆分，准确保留这两个目标的决策。经济策略在组内允许分数分配；分组细化可能轻微改变旧南京结果。配置车队以100台整数模块计，设施按原共享比例估计，不进行地理选址。

整体比例由年度总量计算；城市分布不加权。减排保留比例允许负数，碳最优减排量为零时不定义。成本与时间代价分别相对同一经济情景下的经济最优和时间最优。结果总结报告增排城市数、整体指标、城市中位数及未定义比例。
