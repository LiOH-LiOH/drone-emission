## 核实结论

已查到可追溯的工资、维护费、电池寿命和多机监管参照，但尚未取得一套适用于中国成熟外卖无人机的完整、实测、同口径参数。不能把“发表于高质量期刊”直接理解为“参数经过实测校准”。本轮未设定模型基准值，未运行 Python、测试或模型。

证据分为：A=原始运营/企业披露（仍需辨别披露口径）；B=原论文明确给出的模型输入（区分访谈与预测）；C=论文或报告引用他人估计，底层未独立核实；D=缺失或尚未读到关键全文/补充表。

## 已纠正的引用和口径风险

1. **0.091 USD/mile不是无人机维护单价。** Zhang 2026 §5.1.1.3将其定义为含人工、维护、电池更换、控制系统及带宽的非能源综合成本，引用Keeney 2020（ARK投资研究）及Zhang 2024（Omega）。已经单列这些分项时不能再叠加0.091。文献中出现该值不构成中国实测验证。
2. **Baldisseri的“未来”情景不符合本研究全部边界。** §4明确未来情景无需人类飞手；我们保留监管人工，不能整套复制未来情景后称已计入人工。维护、电池等参数可以单独讨论。
3. **Lemardelé的2.1 EUR/机时不是纯运维总价。** Table 11包含折旧0.24、维护0.24、保险0.80和结构性费用0.80 EUR/机时；按分项去掉折旧为1.84 EUR/机时（本核实的算术推导）。这仍未证明覆盖本研究要求的独立飞手、地勤、电能和电池更换费用，不作为完整OPEX输入。
4. **电池单价与能量吞吐费用要分开。** Baldisseri Table F1列Battery Cost为175/87.5/43.75 EUR/kWh；式(11)使用battery cost per kWh used乘年耗能。仅从当前可读正文不能完全消除容量价格与吞吐价格之间的换算歧义，不直接照搬式(11)数值，也不把它当电价。
5. **维修年度费用依赖利用率分摊。** EUR/年不能未经年订单数就换成EUR/单。额定管理50架同样不等于每天都满负荷管理50架。
6. **原始论文身份需核对。** 本地`ye_2024.md`是TR-E的*Modeling and managing an on-demand meal delivery system with order bundling*，DOI为10.1016/j.tre.2024.103597；不是同作者TR-C的混合自主车辆论文104723。本轮工资核实来自前者。

## 第一版可采用的核算结构（方法建议，不是已校准参数）

每种方式的每单成本分解为能源、电池损耗、维修、人工及其他必要经常性费用。所有外部价格保留原币种和价格年份；本轮未作汇率转换。

- 电池损耗：`C_batt,i = P_pack × E_batt,i / (N_EFC × E_usable)`。E_batt,i为整个任务从电池取出的能量，含运营口径下的返程；电价则乘电网购电量，两者充电损耗口径不同。N_EFC和E_usable必须采用一致的等效循环/可用容量定义，并检查日历寿命限制。更换不是每次换电：日常轮换同一组电池不能每次收取新电池购置价。
- 年度维修：`C_maint = M_year / Q_year`。若服务量随替代率变化，需要说明采用给定利用率的情景单位成本；不能同时声称求解了机队规模和全系统固定费用最优。
- 远程监管：`C_remote = 人均年监管人工成本 / 人均年服务订单数`。进一步用管理机数、每机年完成订单和配置利用率解释分母；不要只除管理机数就得到每单费用。
- 地面人工：`C_ground = 地勤总人工成本 / 地勤处理订单数`，或依据可核实的每单人工作业时间分摊。日薪没有对应服务量，不能推出元/单。
- 骑手人工：使用同一群体、同一期间的纯劳动报酬与完成订单数，或同口径工资率与每单分摊工时。不能将“平均收入/在线小时”直接乘顾客单程运输时间，漏掉返程、接单移动、作业及闲置占用。

这些人工占用用于成本分摊，不改变用户已经选择的“仅运输时间”绩效指标，也不要求先新增排队模拟。

## 采用建议与剩余缺口

可以保留500/800/1000次作为**文献情景值**，前提是标明机型与试验条件未在中国场景验证。多机监管可做配比敏感性；Wing的50仅作为外部技术参照，不推荐直接选为基准。维护费参照应保持各研究的整套价格/利用率上下文，不混拼最有利值。

中国基准成本目前仍缺：纯骑手人工报酬及匹配工作量、监管员工资及有效管理负荷、地勤每单工时或每日服务量、对应机型维修报价、电池容量/价格/循环寿命的配套组合、电动车维修。可进行条件性的成本临界分析；尚不能报告经实测校准的中国成本最优替代率。

为保持可复核性，本轮未把Li 2025或行业预测升级为核心学术证据。建议优先使用运输期刊支持核算方法，并用适配的原始运营数据校准价格；若只能用假设，明确输出参数条件下的替代率，而非唯一现实预测。
