# 图片配色标准

## 最新审美方向：更鲜明的固定色表（全图试用）

用户要求提高色彩鲜明度。候选仍由六个彩色组成，冷色与暖色各三种：
蓝 `#123F7A`、青 `#008F9C`、薄荷 `#4CCFB5`、金黄 `#EDBE42`、
橙 `#ED793E`、红 `#D64F4F`；中性色沿用原表。通过提高色彩饱和度
减轻上一版的灰褐感，保留顺序渐变低端对白底的辨识度与高端的深色。
顺序为薄荷 → 青 → 蓝，发散为蓝 → 金黄 → 红；GEF 归一化保持不变。
用户已确认试用，配置为 `src/drone_emission/tools/palette_vivid.json`；
实际绘图配置已同步，最新 `gef-linear_20260911` review 同时修正色条和拟合配色，尚未正式采用。

此方案是项目自定义配色，不是 Nature 官方色表。Nature 官方指南强调
清楚可辨、对比度与一致性，不能概括为统一偏好鲜艳色：
[Nature research figure guide](https://research-figure-guide.nature.com/figures/building-and-exporting-figure-panels/)。
本项目按用户要求不以色盲适配作为本轮设计约束。

本文件记录用户确认的最新要求，优先于旧试色记录。当前方案为
`gef-linear_20260911` 全图 review；未经正式采用不覆盖正式成品。

## 设计目标与固定色表

用户取消色盲适配约束，以整体色系和谐、数值层次清楚、白底可见为目标。
不以色觉模拟作为验收条件。采用鲜明蓝青—金黄橙红体系；全局单色从固定
色表和已登记功能变体中选取，禁止随意增加局部色号。

| 兼容配置键 | 色号 | 当前含义 |
| --- | --- | --- |
| `base.blue` | `#123F7A` | 深蓝 |
| `base.green` | `#008F9C` | 蓝青 |
| `base.cyan` | `#4CCFB5` | 薄荷绿 |
| `base.yellow` | `#EDBE42` | 金黄色 |
| `base.coral` | `#ED793E` | 橙色 |
| `base.purple` | `#D64F4F` | 珊瑚红 |
| `base.gray` | `#BBBBBB` | 中性类别、缺失值 |
| `base.charcoal` | `#333333` | 文字、深色线条 |
| `base.white` | `#FFFFFF` | 背景 |

旧键名保留以兼容缓存，其中 green/purple 不再表示字面的绿/紫色。
无人机深蓝、电助力自行车金黄、自行车蓝青、电动轻便摩托薄荷绿、
燃油轻便摩托橙色、电动汽车珊瑚红、燃油汽车灰；跨图保持一致。
地区与生命周期部件复用同一色表，不额外设计主题色。

保留的功能变体为次级灰 `#777777`、浅灰 `#DDDDDD`、金黄色与白各半的
`derived.yellow_light`，以及由 12% 深蓝／金黄色与 88% 白混合的分区底色。
既有三维结构深灰叠加线不编码数据。透明度单独配置，图例须与数据元素一致。

## 仅两种连续色阶

| 色阶 | 控制色（低 → 中 → 高） | 用途 |
| --- | --- | --- |
| 顺序 | `#4CCFB5` → `#008F9C` → `#123F7A` | 人口、减排、概率、建筑规模、密度，以及图 09a 的 GEF 曲面 |
| 发散 | `#123F7A` → `#EDBE42` → `#D64F4F` | GEF 地图和散点，以及围绕有意义中心的差值 |

控制色直接来自固定色表。使用用户认可的 `palette-vivid_20260911`
完整 257 色 CAM02-UCS 插值表，不仅用端点重新做 RGB 插值。
正值色相跨度适中，通过较深的高值端增强明暗对比；低值不得近白而混入背景。
中性色不作为色阶控制色；金黄色为有色中点。两端无需强制等明度。
离散值从完整色阶采样，不截取前几档而丢失深色端；缺失值灰位于数值色阶之外。
全部值、语义别名、色阶和 GEF 归一化集中在
`src/drone_emission/visualization/palette.toml`。

## GEF 跨图一致性

GEF 使用发散色阶，保留原始数值与单位 kg CO2e/kWh。用户指定中点 **0.3**，
不将原始 GEF 解释为正负值，也不将此参照宣称为环保／污染或减排盈亏阈值。
GEF 地图和散点保留 `TwoSlopeNorm(0.3, vmin=0.05, vmax=0.80)` 分配颜色：
0.05 为深蓝，0.3 为金黄色，0.80 为珊瑚红。色条坐标轴显式设为线性，
不采用 TwoSlopeNorm 自动生成的非等距轴；0.05、0.30、0.55、0.80
在色条上等距，0.3 位于低端起的 1/3 处。颜色分界不要求位于几何正中央。
此规则同时用于横向、纵向色条。

图 09a 为用户指定的例外：使用同一全局顺序色阶，按 0.05–0.80 线性
归一化，突出 GEF 曲面高低；不再要求其颜色与发散地图、散点逐值相同。
它仍保留相同单位、范围和等距色条，避免将例外误解为新的科学数据。

图 3d 拟合配色依据各组 GEF 中位数，从该组散点色阶取色，再混合 22%
固定炭黑以适度加深。拟合线不透明度 0.95，置信区间同色、不透明度 0.11。
此为明确登记的数据派生功能色，不是随意增加固定类别色。

范围依据：已有模型完整域为 0.05–0.80；省级数据和实际城市散点均为
0.1073–0.7252，因此共同范围覆盖全部着色值。范围固定，不逐图自动缩放。
未来科学输入超出范围时重新审计并全图同步，不静默截断。
散点从原分档着色改为连续着色，以保证同值在发散地图和散点中同色；
已有 0.3 分组、拟合、样本和科研数据不变。其他差值变量仍以自己的有意义
中心归一化；同色跨变量不代表相同数值。
